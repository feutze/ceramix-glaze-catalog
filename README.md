# Ceramix Glaze Catalog

A searchable pottery glaze catalog for ARTX548. The public app reads its current inventory from the native Google Sheet and falls back to the bundled `data.json` snapshot if the sheet is temporarily unavailable.

## Live inventory source

`Ceramix Master Glaze Inventory (Live)` — worksheet `Glazes Available`.

The worksheet must remain shared as **Anyone with the link — Viewer** so the public catalog can refresh automatically.
